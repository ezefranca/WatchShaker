# Security Policy

## Supported versions

Security fixes are provided for the latest released major version.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue for a vulnerability that could put applications or users at risk.

Include affected versions, impact, reproduction steps, and any suggested mitigation. You can expect an initial response within seven days.

WatchShaker processes motion data in memory and does not persist or transmit it. Changes that add storage, networking, analytics, or HealthKit integration require explicit documentation and privacy review.
